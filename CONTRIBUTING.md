# Как участвовать

Спасибо, что хотите помочь! Проект маленький и без сборки — начать можно за минуту.

## Запуск

1. Склонируйте репозиторий.
2. `chrome://extensions` → «Режим разработчика» → «Загрузить распакованное» → папка `extension`.
3. После правок нажмите ↻ на карточке расширения. Логи service worker — по ссылке «service worker» там же.

## Правила

- **Без зависимостей и сборки.** Чистый JavaScript, HTML и CSS, которые Chrome загружает как есть.
- **Интерфейс — на русском**, комментарии в коде тоже.
- **Отступ — 2 пробела**, кодировка UTF-8 (см. `.editorconfig`).
- Вся логика, работающая с вкладками, группами и сетью, живёт в `background.js`; попап и настройки только отправляют сообщения.
- Изменения групп выполняйте через `serial()`, чтобы параллельные операции не создавали дубликаты.
- Новые разрешения в `manifest.json` добавляйте только при необходимости и описывайте в README и PRIVACY.md.

## Перед pull request

- Проверьте синтаксис: `node --check extension/*.js`.
- Проверьте вручную: раскладку, авто-режим, «Не подошли никуда», сохранение категорий.
- Добавьте запись в `CHANGELOG.md` в раздел «Не выпущено».
- Если меняли интерфейс — обновите скриншоты в `docs/images`.

## Релиз

1. Поднимите `version` в `extension/manifest.json` и перенесите изменения в `CHANGELOG.md`.
2. Создайте тег `vX.Y.Z` и запушьте его — GitHub Actions соберёт `jev-tabs-X.Y.Z.zip` и прикрепит к релизу.
